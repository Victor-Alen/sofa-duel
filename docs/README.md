# 沙发只能坐一个：六角色高光版

一间房、六名可选角色、一张沙发的短局 1v1 网页游戏。支持单人挑战电脑、本地双人同屏、电脑自动演示、手机竖屏单人操作和联网对战（PeerJS 点对点，无需后端）。无需安装依赖。

v15 在完整保留六角色技能和对局规则的基础上，重点增强角色生命力与回合观感：加入待机呼吸、眨眼观察、跑步前倾、耳朵滞后、施法手势、受击挤压、胜负表情和角色专属配件；六名角色拥有不同音高、波形和性格的施法/受击/胜负声音。每次得分后自动回放最后约 2.4 秒，并根据冲撞、护盾反制、抱枕等关键事件生成高光标题。v14 目录和历史压缩包未改动。

## 直接玩

- 电脑双击 `打开游戏.cmd`，或直接用浏览器打开 `index.html`。
- 电脑双击 `自动演示.cmd` 观看电脑对战；点击“停止演示”返回菜单。
- 玩家一用 `W A S D` 移动、`空格` 使用技能；本地双人时玩家二用方向键移动、`回车` 使用技能。
- 手机竖屏用左侧摇杆移动、右侧按钮使用技能；右上角可暂停。手机端为单人挑战电脑。
- `P` 暂停，`R` 重新开局，`Esc` 退出大屏。暂停页也可重新开局或返回选角。
- 结算后可“再来一局”、“换角色”或生成战绩海报。

## 六名角色

| 角色 | 技能 | 效果 | 冷却 |
| --- | --- | --- | ---: |
| 珊珊 | 冲撞 | 向面朝方向突进，碰到对手将其撞开 | 2.5 秒 |
| 蓝蓝 | 护盾 | 挡住冲撞、震波、引力、闪现、抱枕或弹簧，并可反击 | 2.6 秒 |
| 团团 | 震波 | 立即震开身边的对手 | 2.8 秒 |
| 闪闪 | 闪现 | 向面朝方向瞬移，并震开落点附近的对手 | 2.8 秒 |
| 柚柚 | 引力 | 牵引附近对手片刻，再将其弹开 | 3.1 秒 |
| 米米 | 抱枕阵 | 留下需要短暂准备的抱枕，困住踩到的对手 | 3.2 秒 |

单人模式可自由选择自己的角色，电脑随机使用其余角色之一。本地双人可分别选择，也允许同角色对战。自动演示随机展示角色组合。角色配置集中在 `characters.js`，扩展方法见 [EXTENDING.md](EXTENDING.md)。

## 角色表现与高光

- 角色会根据移动、施法、受击、占领和胜负改变动作与表情。冲刺有前倾和残影，护盾与引力有张手动作，米米有抛抱枕手势，闪闪有星星配饰；所有动作仅改变画面，不延迟输入，也不改变碰撞、冷却和技能判定。
- 六名角色使用不同音高和波形合成施法、受击、反制与胜负声音。右上角可关闭声音；浏览器首次播放声音需要一次点击或按键。
- 得分后自动播放本回合最后约 2.4 秒的高光，标题优先对应最近的冲撞、护盾反制、震波、闪现、引力或抱枕事件。点击画面、点击“跳过回放”，或按空格、回车、Esc 可提前结束。暂停会冻结回放，重新开局和返回选角会清空缓存。
- 回放缓存只保存在当前页面内存中，采用半分辨率、每秒 12 帧，不会生成视频文件或上传任何内容。2.4 秒时长和动作幅度是待真人试玩继续调优的表现参数。

## 得分与房间规则

只有一个人靠近沙发时，占领进度才增加；累计独占 1.6 秒得 1 分，双方都在范围内时进度暂停。每回合 18 秒，先得 3 分获胜。

时间到时，占领进度较高者得分；进度相同则离沙发更近的一方险胜。距离也完全相同时重赛一次，连续完全平局则公平抽签决定该回合，避免自动演示无限僵持。

| 随机规则 | 发生的事 |
| --- | --- |
| 沙发搬家 | 预告新位置，再把沙发移过去 |
| 弹簧沙发 | 提前闪光预告，把附近的人弹开 |
| 技能狂欢 | 双方技能冷却缩短 32% |
| 贴身角力 | 怼在一起时疯狂点击，先点满 8 次者得分，点得越多撞得越远 |
| 沙发变变变 | 沙发周期性缩小和变大，占领圈跟着变 |

正常对局避免连续两回合出现同一种规则。可在 `index.html` 后加 `?rule=shuffle`、`?rule=spring`、`?rule=frenzy`、`?rule=mash`（贴身角力）或 `?rule=morph`（沙发变变变）固定规则；`?record=1` 可进入竖屏自动演示。

## 验证

- `node smoke.cjs`：使用本机 Microsoft Edge 检查六角色选择、动作与六种技能冷却/渲染、高光出现及跳过、完整比赛、本地双人、手机触控、暂停菜单、海报、竖屏演示和大屏布局，并生成实际页面截图。
- `node balance.cjs`：调用真实游戏循环，检查三种规则下全部 36 种有序角色组合，每组 12 局，共 1,296 局；同时验证闪现、引力两段效果、抱枕准备时间、护盾克制、施法情绪和高光标题。最近一次结果见 [BALANCE.md](BALANCE.md)。

自动化结果证明流程可运行，不等于真人角色平衡结论；新角色数值仍应通过真人试玩继续调整。

## 项目文件

- `index.html`、`style.css`：页面和响应式界面。
- `characters.js`、`rules.js`：角色、技能、数值和随机规则配置。
- `game.js`：对战逻辑、电脑对手、技能效果、绘制和音效。
- `打开游戏.cmd`、`自动演示.cmd`：Windows 快捷启动。
- `smoke.cjs`、`balance.cjs`：浏览器验收与对局稳定性检查。
- `preview.png`、`mobile-menu.png`、`playing.png`、`highlight.png`、`skill-blink.png`、`skill-magnet.png`、`skill-trap.png` 等：测试时生成的真实页面截图。

若浏览器限制本地文件，可在本目录运行 `python -m http.server 8000`，再打开 `http://localhost:8000`。联网对战通过 WebRTC 点对点连接，仅信令经过公共 PeerJS 服务器；当前版本没有账号或排行榜，也不会自动发布任何内容。联机使用说明见 ONLINE_SETUP.md。
